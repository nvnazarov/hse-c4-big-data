# Home Assignment No. 5

## Task

### Steps

1. Поднять S3, Airflow, Spark, Hive Metastore
2. Загрузить синтетические данные в S3 Minio (или S3 Ozone) для каждой таблицы в формате csv
3. Настроить Iceberg таблицы для отображения данных с помощью SQL like запросов из Spark/ Trino
4. Написать SPARK application приложение, выполняющее запросы из задания. Результат должен
   записываться во внешнюю СУБД (предпочтительно Starrock или Dorris или PostgreSQL)
5. Оркестрация задач должна быть из Airflow. Разделение тасков - это 1 SQL-запрос, 1 операция.
   Не делать много задач трансформаций в 1 таску.
6. (Дополнительно) Сделать такую же обработку на движке Trino. Получить точно такой же
   результат, что и на Spark. Результат положить "рядом" во внешнюю БД. Сравнить результаты работы.

### Queries

1. Для каждого клиента вывести ФИО и общую сумму его кредитов, а также сумму по всем кредитам (CLIENT + credits, SUM() OVER()).
2. Для каждого клиента вывести ФИО, id вклада и сумму вклада, а также максимальную сумму вклада клиента.
3. Для каждой транзакции вывести id транзакции, ФИО отправителя и сумму перевода, а также среднюю сумму перевода по всем транзакциям отправителя.
4. Для каждого актива вывести id актива, ФИО владельца и количество, а также суммарное количество активов клиента.
5. Для каждого клиента вывести ФИО и зарплату, а также ранг зарплаты в пределах его отрасли.
6. Для каждого кредита вывести id кредита, ФИО клиента и сумму, а также порядковый номер кредита клиента.
7. Для каждого вклада вывести id вклада, ФИО клиента и сумму, а также среднюю сумму вкладов по всем клиентам.
8. Для каждой транзакции вывести id транзакции, тип счёта отправителя и сумму, а также кумулятивную сумму переводов где данный счёт был отправителем.
9. Для каждого клиента вывести ФИО и процент по кредиту, а также минимальный процент среди всех кредитов клиента.
10. Для каждой выплаты по кредиту вывести id выплаты и сумму выплаты, а также максимальную выплату по кредиту.

### Database Schema

Таблица `actives`:

| Column               | Description              |
|----------------------|--------------------------|
| id              (PK) | Уникальный идентификатор |
| bank_account_id (FK) | Идентификатор счета      |
| instrument_id   (FK) | Внешний ключ             |
| count                | Количество               |
| dt                   | Дата                     |

Таблица `instruments`:

| Column  | Description                        |
|---------|------------------------------------|
| id (PK) | Уникальный идентификатор котировки |
| dt      | Дата начала актуальной стоимости   |
| cost    | Стоимость                          |

\* Стоимость меняется при добавлении новой записи с одинаковым id но более свежим date

Таблица `bank_accounts`:

| Column         | Description                     |
|----------------|---------------------------------|
| id        (PK) | Уникальный идентификатор счета  |
| dt_loaded (PK) | Время загрузки записи в систему |
| client_id (FK) | Идентификатор клиента-владелеца |
| dt_created     | Дата открытия счета             |
| type           | Тип счета                       |

\* В таблице несколько записей о счете актуальный - с последним dt_loaded

Таблица клиентов `clients`:

| Column         | Description                      |
|----------------|----------------------------------|
| id        (PK) | Уникальный идентификатор клиента |
| full_name      | ФИО                              |
| city_name      | Город проживания                 |
| gender         | Пол                              |
| dt_birthday    | Дата рождения                    |

Таблица ключевых ставок Центробанка `key_rates`:

| Column         | Description |
|----------------|-------------|
| dt_since  (PK) | Дата начала |
| percent        | Процент     |

\* Эта таблица - только для справки, не имеет явных зависимостей
   с другими таблицами.

Таблица `deposits`:

| Column         | Description                       |
|----------------|-----------------------------------|
| id        (PK) | Уникальный идентификатор депозита |
| client_id (FK) | Идентификатор клиента             |
| dt_opened      | Дата открытия вклада              |
| dt_closed      | Дата закрытия вклада              |
| amount         | Сумма на момент открытия          |
| percent        | Процент на весь период вклада     |
| type           | Тип вклада                        |

Таблица профилей клиентов `profiles`:

| Column         | Description                      |
|----------------|----------------------------------|
| id        (PK) | Уникальный идентификатор профиля |
| client_id (FK) | Идентификатор клиента            |
| work_company   | Место работы                     |
| work_area      | Отрасль                          |
| salary         | Зарплата                         |
| dt_loaded      | Дата загрузки записи в систему   |

Таблица кредитов `credits`:

| Column         | Description                      |
|----------------|----------------------------------|
| id        (PK) | Уникальный идентификатор кредита |
| client_id (FK) | Идентификатор клиента            |
| dt_started     | Дата открытия кредита            |
| amount         | Сумма кредитования               |
| percent        | Процент                          |
| type           | Тип кредита                      |

Таблица транзакций `transactions`:

| Column                     | Description                         |
|----------------------------|-------------------------------------|
| id        (PK)             | Уникальный идентификатор транзакции |
| from_bank_account_id (FK)  | Идентификатор счета отправителя     |
| to_bank_account_id (FK)    | Идентификатор счета получателя      |
| amount                     | Сумма первода                       |
| dt                         | Дата                                |
| is_successful              | Флаг успешности транзакции          |

Таблица платежей по кредиту `credit_payments`:

| Column               | Description                      |
|----------------------|----------------------------------|
| id              (PK) | Уникальный идентификатор платежа |
| credit_id       (FK) | Идентификатор кредита            |
| bank_account_id (FK) | Идентификатор счета              |
| dt                   | Дата выплаты                     |
| amount               | Сумма выплаты                    |
| is_successful        | Флаг успешности транзакции       |
